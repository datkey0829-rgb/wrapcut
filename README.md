# WrapCut

A small video editor that runs entirely in your browser — one HTML file, no server, no upload.

Open: https://datkey0829-rgb.github.io/wrapcut/

- Import video / image / music (stays in your browser).
- Timeline: trim, split, reorder, speed, volume, punch-in zoom, fade in.
- Text overlays (emoji supported), background music with fade-out.
- Export 9:16 / 1:1 / 4:5 / 16:9 at 1080p or 720p (MP4 on recent Chrome/Edge, WebM otherwise). Export runs in real time — keep the tab open.
- 🎯 Learn a style from a sample video: scene cuts, music BPM / cut-on-beat, hook text via OCR (Tesseract.js).
- ✨ Apply it to your clips: auto-pick the best (sharp, moving, well-lit) segments, snap cuts to the music beat, freeze or slow down short clips.
